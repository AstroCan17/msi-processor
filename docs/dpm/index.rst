Detailed processing model
=========================

This section describes the Detailed processing model (DPM) for the data
processing. It shall cover the complete processing, as defined in the
Algorithm Theoretical Basis Definition (ATBD) document.

.. note::

  In order to ensure the consistency of the delivered documentation with
  the current implementation, a Data Processor shall provide
  a Detailed processing model (DPM).

  The DPM shall detail all the algorithms implemented within the processor,
  including the algorithms defined to optimize the processing performances,
  from the tutorials and prototype code (i.e. Jupyter Notebooks)
  developed in the frame of the project.
